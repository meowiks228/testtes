# Лагерь Локиленд — тест имён

Статический адаптивный сайт для подбора имён 14 персонажам. Проект не требует сборки, npm или сервера и подходит для GitHub Pages.

## Как это работает

1. Участник открывает `index.html`, вводит имя или псевдоним и отвечает на 14 вопросов.
2. Для каждого персонажа доступны все 14 имён; мужские и женские имена разделены только визуально.
3. Одно имя нельзя использовать дважды в рамках одной анкеты.
4. После проверки участник нажимает «Поделиться» и отправляет читаемый список ответов через системное меню телефона.
5. CSV-файл автоматически скачивается как запасная копия и подходит для импорта в локальную админ-панель.
6. Администратор открывает `admin.html`, импортирует один или несколько CSV-файлов и присваивает анкетам свои метки.

## Локальный запуск

Можно открыть `index.html` напрямую. Для максимально точной проверки лучше запустить простой статический сервер:

```bash
python -m http.server 8000
```

Затем открыть:

- тест: `http://localhost:8000/`
- панель: `http://localhost:8000/admin.html`

## Публикация на GitHub Pages

1. Создайте новый репозиторий на GitHub.
2. Загрузите в корень репозитория все файлы этого проекта.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main`, папку `/ (root)` и нажмите **Save**.
6. GitHub покажет публичную ссылку через несколько минут.

Все пути в проекте относительные, поэтому сайт работает и по адресу вида `username.github.io/repository/`.

## Панель администратора и хранение

`admin.html` — статическая локальная панель. Она:

- импортирует результаты `.csv`;
- проверяет формат, количество ответов, известность и уникальность имён;
- отделяет анкеты по уникальному ID;
- позволяет задать собственную метку каждой анкете;
- экспортирует общую CSV-таблицу;
- сохраняет и восстанавливает резервную копию в JSON.

Данные панели находятся в `localStorage` **только того браузера и устройства, где выполнен импорт**. GitHub Pages не предоставляет сервер или базу данных. Поэтому регулярно используйте кнопку **BACKUP JSON**.

Админ-страница не содержит фиктивной парольной защиты: любой пароль в статическом JavaScript можно увидеть. Однако посетитель страницы не увидит ваши импортированные результаты, потому что они не загружаются на GitHub и остаются локально в вашем браузере.

## Проверка

При установленном Node.js:

```bash
node --check assets/data.js
node --check assets/utils.js
node --check assets/app.js
node --check assets/admin.js
node --test tests/utils.test.js
```

## Приватность

Файл результата содержит имя/псевдоним участника, дату прохождения, уникальный ID и 14 выбранных имён. Он не содержит IP-адрес, cookies или данные об устройстве.
